# Publication Package Checklist

To make this repository publication-ready, prioritize these improvements.

## Package Structure

- Keep `NAMESPACE` generated by `roxygen2`.
- Add function-level documentation for public wrappers.
- Decide which functions are exported and which remain internal helpers.
- Keep a package-level help page, for example `?PeakAnnoAgent`.
- Keep `LICENSE` and citation metadata through `inst/CITATION`.

## Reproducibility

- Add `renv.lock` or a Bioconductor Dockerfile.
- Record package versions in every run output.
- Save a machine-readable run manifest with inputs, species, methods, cutoffs, and timestamps.
- Keep raw data out of Git and provide small example data only.

## Method Rigor

- Make the enrichment universe mandatory or strongly warned for local ORA methods.
- Add support for ID conversion reports, including unmapped genes.
- Save both raw and filtered enrichment tables.
- Add method-specific notes for API-backed tools whose background database is external.

## Figures

- Standardize figure themes, palettes, font sizes, and output dimensions.
- Export PDF as the primary manuscript format and optionally PNG for previews.
- Add figure unit tests that check output files are created and non-empty.
- Add parameters for title, top term count, p-adjust cutoff, and color scale limits.

## Testing And CI

- Expand offline tests for CLI parsing, method validation, and export functions.
- Add conditional tests for Bioconductor methods when packages are installed.
- Add GitHub Actions for syntax checks and offline tests.
- Add example workflow tests that do not require network access.

## User Interface

- Keep the CLI as the stable backend contract.
- Add a Shiny app after the CLI is stable.
- Use a REST API only if external apps need to submit jobs.
