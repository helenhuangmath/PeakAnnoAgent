# Bundled example data

| File | What it is |
|---|---|
| `example_tex_peaks_mm10.bed` | Synthetic mm10 peak set (351 peaks) placed at promoters and nearby distal sites of T-cell exhaustion and effector genes, plus random background. Not real data. |
| `example_tex_biology.json`, `example_tex_signatures.gmt`, `example_tex_rnaseq_de.tsv` | Biology description, synthetic exhaustion signatures and a synthetic differential-expression table for the same example. |
| `example_ctcf_k562_hg38.bed` | CTCF ChIP-seq in K562, ENCODE ENCFF582SNT, hg38, 1000 strongest peaks. |
| `example_h3k27ac_cd8_hg38.bed` | H3K27ac ChIP-seq in human CD8 T cells, ENCODE ENCFF283CAQ, hg38, 1000 strongest peaks. |
| `example_h3k4me3_bmdm_mm10.bed` | H3K4me3 ChIP-seq in mouse bone-marrow macrophages, ENCODE ENCFF813FPW, mm10, 800 strongest peaks. |
| `example_*_biology.json` | The biology description used with each ENCODE example. |
| `example_peaks.bed`, `example_annotation.tsv`, `example_enrichment.tsv`, `example_cluster_genes.tsv` | Small tables used by tests. |
